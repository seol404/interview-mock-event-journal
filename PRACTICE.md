# Patchwork interview practice: Event Journal

Original practice exercises, not actual interview questions.

## Run
Requires Node.js 18 or later. No dependencies need to be installed.

    npm test

Failures are intentional. Read README.md and the documented contracts.

## Agent handoff
You are my coding assistant in an interview practice session. This repository is intentionally incomplete. Use README.md as the behavior contract and investigate the implementation.

First inspect the repository and run npm test. Summarize its structure and failures before editing. Work on one behavior at a time. Add a regression that fails before the repair, propose a minimal patch, and explain every changed line. Do not fix unrelated issues or change public interfaces. Stop for my review before applying a candidate patch. Rerun relevant tests after each accepted change. Do not remove or weaken assertions to make tests pass.



## Workflow
Establish a baseline; add regression tests; review diffs with reasons; verify after edits; explain remaining uncertainty.

## Return to the lab
Open the matching session, choose Use your agent, and import this folder. Matching source files will be proposed for review. Tests added locally are not automatically imported; use View tests to add their assertions in the website. Held-out evaluation cases stay in the website until you finish.
